我来为您详细讲解如何在 GreenTraffic 项目中实现 Spring Events 和 RocketMQ 双基础设施架构，并支持开发/测试环境切换。

## 一、整体架构设计

### 1.1 设计思路

```
                    ┌─────────────────────────────────┐
                    │   Traffic Data Producer         │
                    └────────────┬────────────────────┘
                                 │
                    ┌────────────▼────────────────────┐
                    │   Message Infrastructure        │
                    │   (Strategy Pattern)            │
                    └────────────┬────────────────────┘
                                 │
                 ┌───────────────┼───────────────┐
                 │               │               │
        ┌────────▼─────┐  ┌──────▼──────┐  ┌─────▼─────┐
        │ Spring Events│  │  RocketMQ   │  │  Kafka    │
        │ (Dev Env)    │  │ (Test Env)  │  │ (Future)  │
        └──────────────┘  └─────────────┘  └───────────┘
```

### 1.2 核心设计模式

1. **策略模式**：不同的消息基础设施实现统一接口
2. **工厂模式**：根据环境创建对应的基础设施
3. **条件注解**：使用 `@ConditionalOnProperty` 实现环境切换
4. **事件驱动**：使用 Spring Events 作为开发环境的轻量级方案

```java
        SimpleApplicationEventMulticaster eventMulticaster = 
            new SimpleApplicationEventMulticaster();
        
        // 使用异步执行器

            // 记录错误日志
            System.err.println("Spring Event 处理错误: " + throwable.getMessage());
        });
        
        return eventMulticaster;
    }
    
    /**
     * 创建 Spring Event 基础设施
     */
    @Bean
    public SpringEventInfrastructure springEventInfrastructure() {
        return new SpringEventInfrastructure();
    }
}
```

```java
package com.greentraffic.infrastructure.messaging.spring;

import com.greentraffic.infrastructure.messaging.core.MessagePublisher;
import com.greentraffic.infrastructure.messaging.core.TrafficMessage;
import lombok.extern.slf4j.Slf4j;
import org.springframework.context.ApplicationEventPublisher;

import java.util.List;
import java.util.concurrent.CompletableFuture;

/**
 * Spring Event 发布器
 * 将消息包装为 Spring Event 并发布
 */
@Slf4j
public class SpringEventPublisher implements MessagePublisher {
    
    private final ApplicationEventPublisher eventPublisher;
    
    public SpringEventPublisher(ApplicationEventPublisher eventPublisher) {
        this.eventPublisher = eventPublisher;
    }
    
    @Override
    public <T> void publish(String topic, T message) {
        TrafficEvent<T> event = new TrafficEvent<>(topic, message);
        eventPublisher.publishEvent(event);
        log.debug("Spring Event 发布消息到 {}: {}", topic, message);
    }
    
    @Override
    public <T> CompletableFuture<Void> publishAsync(String topic, T message) {
        return CompletableFuture.runAsync(() -> publish(topic, message));
    }
    
    @Override
    public <T> void publishBatch(String topic, List<T> messages) {
        for (T message : messages) {
            publish(topic, message);
        }
        log.info("Spring Event 批量发布 {} 条消息到 {}", messages.size(), topic);
    }
    
    /**
     * Spring Event 包装类
     */
    public static class TrafficEvent<T> extends org.springframework.context.ApplicationEvent {
        
        private final String topic;
        private final T message;
        private final long timestamp;
        
        public TrafficEvent(String topic, T message) {
            super(message);
            this.topic = topic;
            this.message = message;
            this.timestamp = System.currentTimeMillis();
        }
        
        public String getTopic() {
            return topic;
        }
        
        public T getMessage() {
            return message;
        }
        
        public long getTimestamp() {
            return timestamp;
        }
    }
}
```

```java
package com.greentraffic.infrastructure.messaging.spring;

import com.greentraffic.infrastructure.messaging.core.MessageSubscriber;
import lombok.extern.slf4j.Slf4j;
import org.springframework.context.event.EventListener;
import org.springframework.stereotype.Component;

import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

/**
 * Spring Event 订阅器
 * 使用 @EventListener 注解监听事件
 */
@Slf4j
@Component
public class SpringEventSubscriber implements MessageSubscriber {
    
    private final Map<String, MessageHandler<?>> handlers = new ConcurrentHashMap<>();
    
    @Override
    public <T> void subscribe(String topic, Class<T> messageType, MessageHandler<T> handler) {
        handlers.put(topic, handler);
        log.info("订阅 Spring Event topic: {}", topic);
    }
    
    @Override
    public void unsubscribe(String topic) {
        handlers.remove(topic);
        log.info("取消订阅 Spring Event topic: {}", topic);
    }
    
    /**
     * 处理 Spring Event
     */
    @EventListener
    public void handleEvent(SpringEventPublisher.TrafficEvent<?> event) {
        String topic = event.getTopic();
        Object message = event.getMessage();
        
        @SuppressWarnings("unchecked")
        MessageHandler<Object> handler = (MessageHandler<Object>) handlers.get(topic);
        
        if (handler != null) {
            try {
                handler.handle(message);
                log.debug("处理 Spring Event 消息: {}", message);
            } catch (Exception e) {
                log.error("处理 Spring Event 消息失败", e);
            }
        } else {
            log.warn("未找到 topic {} 的处理器", topic);
        }
    }
}
```

```java
package com.greentraffic.infrastructure.messaging.rocketmq;

import com.alibaba.fastjson.JSON;
import com.greentraffic.infrastructure.messaging.core.MessagePublisher;
import com.greentraffic.infrastructure.messaging.core.TrafficMessage;
import lombok.extern.slf4j.Slf4j;
import org.apache.rocketmq.client.producer.DefaultMQProducer;
import org.apache.rocketmq.client.producer.SendResult;
import org.apache.rocketmq.common.message.Message;

import java.nio.charset.StandardCharsets;
import java.util.List;
import java.util.concurrent.CompletableFuture;

/**
 * RocketMQ 发布器
 */
@Slf4j
public class RocketMQPublisher implements MessagePublisher {
    
    private final DefaultMQProducer producer;
    
    public RocketMQPublisher(DefaultMQProducer producer) {
        this.producer = producer;
    }
    
    @Override
    public <T> void publish(String topic, T message) {
        try {
            TrafficMessage trafficMessage = TrafficMessage.of(
                message.getClass().getSimpleName(), 
                message
            );
            
            String json = JSON.toJSONString(trafficMessage);
            Message rocketMessage = new Message(
                topic,
                json.getBytes(StandardCharsets.UTF_8)
            );
            
            SendResult result = producer.send(rocketMessage);
            log.debug("RocketMQ 发送消息成功: {}, msgId: {}", 
                message, result.getMsgId());
            
        } catch (Exception e) {
            log.error("RocketMQ 发送消息失败", e);
            throw new RuntimeException("RocketMQ 发送失败", e);
        }
    }
    
    @Override
    public <T> CompletableFuture<Void> publishAsync(String topic, T message) {
        return CompletableFuture.runAsync(() -> publish(topic, message));
    }
    
    @Override
    public <T> void publishBatch(String topic, List<T> messages) {
        for (T message : messages) {
            publish(topic, message);
        }
        log.info("RocketMQ 批量发送 {} 条消息到 {}", messages.size(), topic);
    }
}
```

#### RocketMQSubscriber.java
```java
package com.greentraffic.infrastructure.messaging.rocketmq;

import com.alibaba.fastjson.JSON;
import com.greentraffic.infrastructure.messaging.core.MessageSubscriber;
import com.greentraffic.infrastructure.messaging.core.TrafficMessage;
import lombok.extern.slf4j.Slf4j;
import org.apache.rocketmq.client.consumer.DefaultMQPushConsumer;
import org.apache.rocketmq.client.consumer.listener.ConsumeConcurrentlyStatus;
import org.apache.rocketmq.client.consumer.listener.MessageListenerConcurrently;
import org.apache.rocketmq.common.message.MessageExt;

import java.nio.charset.StandardCharsets;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

/**
 * RocketMQ 订阅器
 */
@Slf4j
public class RocketMQSubscriber implements MessageSubscriber {
    
    private final DefaultMQPushConsumer consumer;
    private final Map<String, MessageHandler<?>> handlers = new ConcurrentHashMap<>();
    
    public RocketMQSubscriber(DefaultMQPushConsumer consumer) {
        this.consumer = consumer;
        setupMessageListener();
    }
    
    private void setupMessageListener() {
        consumer.registerMessageListener((MessageListenerConcurrently) (msgs, context) -> {
            for (MessageExt msg : msgs) {
                String topic = msg.getTopic();
                String content = new String(msg.getBody(), StandardCharsets.UTF_8);
                
                @SuppressWarnings("unchecked")
                MessageHandler<Object> handler = (MessageHandler<Object>) handlers.get(topic);
                
                if (handler != null) {
                    try {
                        TrafficMessage trafficMessage = JSON.parseObject(content, TrafficMessage.class);
                        handler.handle(trafficMessage.getPayload());
                        log.debug("处理 RocketMQ 消息: {}", content);
                    } catch (Exception e) {
                        log.error("处理 RocketMQ 消息失败", e);
                        return ConsumeConcurrentlyStatus.RECONSUME_LATER;
                    }
                }
            }
            return ConsumeConcurrentlyStatus.CONSUME_SUCCESS;
        });
    }
    
    @Override
    public <T> void subscribe(String topic, Class<T> messageType, MessageHandler<T> handler) {
        handlers.put(topic, handler);
        try {
            consumer.subscribe(topic, "*");
            log.info("订阅 RocketMQ topic: {}", topic);
        } catch (Exception e) {
            log.error("订阅 RocketMQ topic 失败: {}", topic, e);
        }
    }
    
    @Override
    public void unsubscribe(String topic) {
        handlers.remove(topic);
        try {
            consumer.unsubscribe(topic);
            log.info("取消订阅 RocketMQ topic: {}", topic);
        } catch (Exception e) {
            log.error("取消订阅 RocketMQ topic 失败: {}", topic, e);
        }
    }
}
```

```java
        switch (properties.getType()) {
            case SPRING_EVENT:
                infrastructure = springEventInfrastructure;
                break;
            case ROCKETMQ:
                infrastructure = rocketMQInfrastructure;
                break;
            default:
                throw new IllegalArgumentException(
                        "不支持的消息基础设施类型: " + properties.getType()
                );
        }

        if (infrastructure != null) {
            infrastructure.initialize();
        }

        return infrastructure;
    }

    @PreDestroy
    public void destroy() {
        if (springEventInfrastructure != null) {
            springEventInfrastructure.destroy();
        }
        if (rocketMQInfrastructure != null) {
            rocketMQInfrastructure.destroy();
        }
    }
}
```

## 六、总结

### 6.1 架构优势

1. **环境隔离**：开发/测试环境使用不同的消息基础设施
2. **统一接口**：业务代码无需关心底层实现
3. **灵活切换**：通过配置文件轻松切换
4. **易于扩展**：可以方便地添加新的基础设施

### 6.2 最佳实践

1. 开发环境使用 Spring Event：快速、轻量、无需外部依赖
2. 测试环境使用 RocketMQ：模拟生产环境，测试分布式场景
3. 生产环境可考虑 Kafka 或 RocketMQ：高性能、高可用

### 6.3 注意事项

1. Spring Event 不支持跨 JVM 通信
2. RocketMQ 需要额外的运维成本
3. 消息序列化需要统一规范
4. 需要处理消息重复消费问题

这种设计使得系统在不同环境下都能高效运行，同时保持代码的一致性和可维护性。
