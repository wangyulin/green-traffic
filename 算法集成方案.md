# 二、关键点：算法不是 Domain

这是你这个项目现在最需要注意的地方。

比如你想增加：

* XGBoost
* LightGBM
* Random Forest
* Prophet
* Statsmodels
* KNN
* SVM
* SHAP

千万不要这样：

```text
green-traffic-core
    │
    ├── XGBoostService
    ├── LightGBMService
    ├── RandomForestService
    ├── ProphetService
    └── SHAPService
```

这样很快就会把 Core 变成一个“算法大杂烩”。

因为：

```text
XGBoost
LightGBM
RandomForest
Prophet
Statsmodels
sklearn
SHAP
```

都是**技术实现**，而不是交通领域的业务概念。

例如：

> “预测未来 30 分钟路口碳排放”

这是业务能力。

而：

> “使用 XGBoost 预测”

这是技术实现。

这两个概念一定要分开。
