# GreenTraffic 课程计划（整合版）

说明：本文件基于 `课程计划_v1.md`、`课程计划_v2.md`、`课程计划_v3.md` 与项目 README 的内容整合而成，目标是把 GreenTraffic 项目作为贯穿主线的实战课程，按周/节给出清晰教学目标、实战任务与考核要求。

先修要求
- 有编程基础（Java 基础语法、面向对象概念）
- 基本终端/Linux 操作、基本 SQL 知识

总览
- 节数：24 次课，每次 2 小时（共 48 小时），可按 12 周 × 每周 2 次排期；也可扩展为 36 次更细化版本。
- 教学方式：讲解（约 60 分钟）+ 实战编码（约 50 分钟）+ 答疑/代码 review（约 10 分钟）。
- 目标产出：可演示的 GreenTraffic 项目（含 API 文档、模拟数据、实时大屏、优化建议模块、部署说明）。

项目与参考代码
- 项目启动入口：[green-traffic-api/src/main/java/com/greentraffic/api/GreenTrafficApplication.java](green-traffic-api/src/main/java/com/greentraffic/api/GreenTrafficApplication.java#L1)
- 示例控制器： [green-traffic-api/src/main/java/com/greentraffic/api/controller/HelloController.java](green-traffic-api/src/main/java/com/greentraffic/api/controller/HelloController.java#L1)
- 统一响应类： [green-traffic-common/src/main/java/com/greentraffic/common/api/ApiResponse.java](green-traffic-common/src/main/java/com/greentraffic/common/api/ApiResponse.java#L1)
- 模拟器示例： [green-traffic-simulator/src/main/java/com/greentraffic/simulator/TrafficSensorSimulator.java](green-traffic-simulator/src/main/java/com/greentraffic/simulator/TrafficSensorSimulator.java#L1)
- 数据模型示例： [green-traffic-model/src/main/java/com/greentraffic/model/entity/TrafficData.java](green-traffic-model/src/main/java/com/greentraffic/model/entity/TrafficData.java#L1)

总体模块与技术栈（精简）
- Java 17、Spring Boot 3、Maven、Lombok、Jackson
- 数据库：MySQL（主） + InfluxDB（时序，可选）
- 持久层：MyBatis 或 Spring Data JPA（按教学侧重点选）
- 实时：WebSocket（STOMP 可选）
- 消息：RabbitMQ（或 Kafka 引导讨论）
- 部署：Jar / Docker，README 与 docker-compose 演示

考核与 Capstone 要求
- Capstone（必做）：实现一套完整功能并提交 PR + 10 分钟演示，要求包含：
  - TrafficData CRUD API（分页、排序、过滤）并有 Swagger 文档与 Postman 集合
  - 数据库索引说明与 SQL 优化说明
  - 统一响应 + 全局异常处理 + 参数校验
  - AOP 日志/耗时埋点
  - WebSocket 实时推送
  - 至少一种异步/解耦实现（消息队列或事件）
  - 定时任务统计并持久化结果
  - README、运行/部署说明与演示材料

评分策略（示例）
- 代码质量与功能完整性：60%
- 文档与演示：20%
- 单元测试与代码规范：10%
- 课堂作业与 PR 参与：10%

每课详细安排（1-24 课）

第1课：课程导入、项目全景与开发环境（第 1 次）
- 目标：理解 GreenTraffic 项目背景、架构，搭建开发环境（JDK17、IDEA、Maven、Docker 可选）
- 实战：创建 Maven 父工程、运行 `green-traffic-api` 启动类并浏览 Hello 接口
- 作业：熟悉代码结构，提交第一次 PR（分支：lesson-01）

第2课：Java 面向对象回顾与项目领域建模（第 2 次）
- 目标：巩固类/接口/继承/多态，完成领域模型设计（Vehicle、TrafficData、RoadSegment、Intersection）
- 实战：在 model 模块补充实体字段，使用 Lombok 简化（在习题中说明何时使用 @Data）
- 作业：为 TrafficData 编写基本单元测试

第3课：Maven 深入、项目工程化与 Git 工作流（第 3 次）
- 目标：理解 pom 管理、插件、构建生命周期；掌握 Git 分支/PR 流程
- 实战：配置 parent pom、创建 .gitignore、完成一次 feature 分支的提交与合并演练
- 作业：将本次代码推送远程并发起 PR

第4课：MySQL 建模与 SQL 实践（第 4 次）
- 目标：完成 ER 设计、核心表建表（traffic_data、intersection、optimization_advice）与索引策略
- 实战：编写并执行建表 SQL，导入样例数据，写 3 条复杂查询
- 作业：优化一条慢查询并提交说明

第5课：JDBC/HikariCP 与 Lombok/Jackson（第 5 次）
- 目标：理解 JDBC 原理、连接池配置；掌握 Jackson 日期与序列化配置
- 实战：手写一个简单 JDBC CRUD（对比 MyBatis），配置 HikariCP；配置全局 ObjectMapper
- 作业：将实体序列化为 JSON 的边界测试

第6课：MyBatis 或 JPA（第 6 次）
- 目标：选用 MyBatis 或 JPA 讲解 DAO 层实现细节与性能考量
- 实战：编写 Mapper（或 Repository）实现 TrafficData 的分页查询与动态筛选
- 作业：实现批量插入接口并做性能测试

第7课：Spring IoC/DI 与 Bean 管理（第 7 次）
- 目标：掌握 Spring IoC、Bean 注入、配置类与属性注入
- 实战：将计算器、服务类注册为 Bean，注入排放因子配置
- 作业：补写配置类并说明配置优先级

第8课：AOP、日志与自定义注解（第 8 次）
- 目标：理解 AOP 原理，使用切面实现请求日志、耗时统计与异常埋点
- 实战：实现 LoggingAspect，对 Service 层方法记录入参/出参/耗时
- 作业：补充单元测试验证切面行为

第9课：REST API 设计、参数校验与统一响应（第 9 次）
- 目标：REST 设计规范、JSR-303 校验、Result/ApiResponse 统一返回结构
- 实战：为路段与排放查询实现 API，加入参数校验与 Swagger 注解
- 作业：编写 API 文档并生成 Postman 集合

第10课：WebSocket 实时推送（第 10 次）
- 目标：掌握 Spring WebSocket（或 STOMP）实现实时数据推送到前端
- 实战：使用 `green-traffic-simulator` 发送模拟数据，建立 WebSocket 连接并推送至前端测试页
- 作业：实现前端简单订阅页面并截图演示

第11课：定时任务与调度策略（第 11 次）
- 目标：掌握 @Scheduled、Cron 表达式、任务线程池与分布式定时任务讨论
- 实战：实现定时统计任务（每分钟/每小时聚合）并写入 DB
- 作业：设计一个“每日汇总”任务并实现

第12课：消息队列（RabbitMQ）与异步解耦（第 12 次）
- 目标：理解 MQ 基本概念与可靠性保证，使用 MQ 做削峰填谷
- 实战：实现 SensorDataProducer（上报）与 SensorDataConsumer（消费、计算、存储）
- 作业：模拟高并发消息并分析吞吐

第13课：InfluxDB 与时序数据策略（第 13 次）
- 目标：时序数据库建模（measurement/tag/field）、写入/查询优化、保留策略
- 实战：将排放时序写入 InfluxDB（或模拟），实现按时间范围聚合查询
- 作业：设计降采样策略并给出实现思路

第14课：性能优化（SQL & API）与分页/缓存策略（第 14 次）
- 目标：慢查询排查、索引调优、接口分页与缓存使用场景（Redis 可选讨论）
- 实战：针对一条慢 SQL 优化并验证性能提升
- 作业：给出 API 与 DB 的性能调优报告

第15课：安全、鉴权与限流（第 15 次）
- 目标：简单介绍认证鉴权（JWT）、接口限流、参数篡改防护
- 实战：为部分管理接口添加 IP 白名单或简单鉴权示例
- 作业：设计一套限流策略并说明实现方式

第16课：JVM 基础与线上问题排查（第 16 次）
- 目标：JVM 内存模型、常用诊断工具（jstack/jmap/jstat）使用
- 实战：制造内存/死锁场景并现场分析（导出堆、jstack 分析）
- 作业：整理 OOM 排查流程文档

第17课：工程化（Maven/CI/CD/Docker）（第 17 次）
- 目标：打包、Dockerfile、docker-compose、基本 CI 思路
- 实战：为 `green-traffic-api` 编写 Dockerfile，准备 docker-compose 示例
- 作业：本地用 docker-compose 启动服务并提交日志

第18课：监控与度量（日志/指标/告警）（第 18 次）
- 目标：日志分级、指标采集（Prometheus 讨论）、健康检查与告警思路
- 实战：实现基础健康检查接口，示范日志结构化方案
- 作业：设计一套监控指标卡片

第19课：系统架构演进与分布式问题（第 19 次）
- 目标：讨论分布式事务、幂等、消息重复消费、分区容错等实战问题
- 实战：对现有单体进行架构拆分讨论，给出改造建议
- 作业：提交一页架构改造方案

第20课：可观测性与埋点（第 20 次）
- 目标：Tracing/Logging/Metric 的实践要点，如何排查线上问题
- 实战：增加 TraceId 传递与日志关联，实现简单链路追踪示例
- 作业：撰写一次完整请求从入口到 DB 的追踪日志样例

第21课：项目集成测试与自动化（第 21 次）
- 目标：单元测试、集成测试、测试数据准备与 API 自动化测试
- 实战：为关键 Service/Controller 编写集成测试（使用 Spring Boot Test）
- 作业：补充测试覆盖并提交报告

第22课：课程回顾与面试题强化（第 22 次）
- 目标：总结要点，盘点面试高频题（Spring、MySQL、JVM、设计模式）
- 实战：白板题模拟、简历项目讲解训练
- 作业：准备 3 分钟项目演讲稿

第23课：Capstone 联调与演练（第 23 次）
- 目标：完成所有模块联调，准备演示数据与脚本
- 实战：团队/个人演练演示流程，预演问答环节
- 作业：完善 README、演示材料

第24课：Capstone 演示、代码评审与课程总结（第 24 次）
- 目标：完成最终演示并做评分，输出学习建议与后续进阶路线
- 实战：10 分钟演示 + 10 分答辩（教师或同学评分）
- 交付物：最终 PR、README、演示 PPT、Postman 集合

附：课程配套材料建议
