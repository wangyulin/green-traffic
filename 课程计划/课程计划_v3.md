# GreenTraffic 教学课程计划

项目：GreenTraffic — 城市交通碳排放实时监测与优化系统

总览
- 总时长：12 周（每周 2 次课，每次 2 小时）
- 目标学员：有编程基础，期望掌握后端工程实战技能、能用项目实战准备大厂实习面试
- 环境：JDK11/17、Maven、IntelliJ IDEA、MySQL（或 Docker）、Postman、Git、Swagger UI
- 代码参考：启动入口 [green-traffic-api/src/main/java/com/greentraffic/api/GreenTrafficApplication.java](green-traffic-api/src/main/java/com/greentraffic/api/GreenTrafficApplication.java#L1)
- 示例控制器：[green-traffic-api/src/main/java/com/greentraffic/api/controller/HelloController.java](green-traffic-api/src/main/java/com/greentraffic/api/controller/HelloController.java#L1)
- 统一响应类型：[green-traffic-common/src/main/java/com/greentraffic/common/api/ApiResponse.java](green-traffic-common/src/main/java/com/greentraffic/common/api/ApiResponse.java#L1)
- 模拟器示例：[green-traffic-simulator/src/main/java/com/greentraffic/simulator/TrafficSensorSimulator.java](green-traffic-simulator/src/main/java/com/greentraffic/simulator/TrafficSensorSimulator.java#L1)
- 数据模型：[green-traffic-model/src/main/java/com/greentraffic/model/entity/TrafficData.java](green-traffic-model/src/main/java/com/greentraffic/model/entity/TrafficData.java#L1)

先修要求
- 基本编程概念、基本 Linux/终端操作、基本 SQL 语法

课程节奏与评估
- 每次课程 2 小时：约 60 分钟讲解 + 50 分钟实战练习 + 10 分钟答疑/作业布置
- 作业与 PR：每周布置小任务，学员通过 Git 提交到 feature 分支并发起 PR
- 期末 Capstone：在项目上实现一套完整功能并提交 PR + 10 分钟演示

周别与教学内容（高阶计划）

第1周：Java 基础与工程入门（2 次课）
- 目标：巩固 OOP、集合、异常、I/O，理解 Maven 工程结构与依赖管理
- 理论要点：类/接口/继承/多态、泛型、常用集合、异常体系、Maven 生命周期
- 实战：在仓库根目录执行 `mvn clean package`，运行应用入口（见上链路）；读懂 `pom.xml`
- 练习：编写针对 `TrafficData` 的单元测试（JUnit）并提交 PR

第2周：Git 协作工作流与代码规范（2 次课）
- 目标：掌握 Git 基本操作、分支策略、PR 与 Code Review
- 理论要点：commit 原则、分支模型（feature/bugfix/release）、rebase 与冲突解决
- 实战：fork/clone 项目，创建 feature 分支，提交代码并发起 PR；进行一次互评
- 练习：解决一次故意制造的冲突题目

第3周：MySQL 基础与数据建模（2 次课）
- 目标：表设计、索引、事务、Explain 优化基础
- 理论要点：范式、索引类型（B-Tree/哈希）、事务隔离级别、慢查询分析
- 实战：为 `TrafficData` 设计建表语句并导入样例数据；编写分析型查询
- 练习：写出并优化 3 条复杂查询

第4周：MyBatis 与持久层（2 次课）
- 目标：掌握 MyBatis 与 Spring Boot 集成、Mapper 编写、动态 SQL
- 理论要点：SqlSession、Mapper 映射、ResultMap、分页实现（PageHelper 或自实现）
- 实战：在 `green-traffic-api` 中加入 MyBatis 配置，完成 `TrafficData` 的 CRUD Mapper
- 练习：实现分页查询 API

第5周：Spring Boot 基础与 REST API 设计（2 次课）
- 目标：理解 Spring Boot 结构、依赖注入、常见注解；设计 RESTful API
- 理论要点：`@RestController`、`@Service`、`@Repository`、配置文件优先级
- 实战：基于 Mapper 实现 Controller 的查询/新增接口，使用 Postman 验证

第6周：Swagger/OpenAPI 与参数校验（2 次课）
- 目标：生成 API 文档并实现参数校验（`javax.validation`）
- 理论要点：OpenAPI 注解、`@Valid`、常用校验注解与自定义校验
- 实战：集成 Swagger UI，给 API 添加校验并演示错误返回

第7周：全局异常处理与统一响应（2 次课）
- 目标：实现 `@ControllerAdvice` 全局异常处理，统一返回格式
- 理论要点：异常分层、状态码约定、日志格式化
- 实战：基于项目中 `ApiResponse` 实现统一响应；添加自定义业务异常示例

第8周：AOP（切面编程）与日志（2 次课）
- 目标：用 AOP 实现日志、请求耗时统计与埋点
- 理论要点：切点表达式、环绕/前置/后置通知、切面优先级
- 实战：实现记录请求参数（脱敏）与耗时的切面，整合 SLF4J/Logback

第9周：WebSocket 实时通信（2 次课）
- 目标：掌握 Spring WebSocket/STOMP，前后端订阅模式
- 理论要点：握手、消息代理、订阅主题、线程与并发注意事项
- 实战：改造 `TrafficSensorSimulator` 推送实时数据到前端；实现简单前端订阅页

第10周：多数据源与事务管理（2 次课）
- 目标：Spring Boot 下配置多数据源、数据源路由与事务边界
- 理论要点：数据源 Bean 定义、`@Primary`、`@Transactional` 的传播行为
- 实战：配置两个数据源（示例：写库/读库或业务/报表），演示事务行为

第11周：定时任务、Lombok 与 Jackson（2 次课）
- 目标：掌握 `@Scheduled` 定时任务、Lombok 使用场景、Jackson 配置
- 理论要点：任务调度策略、Lombok 常用注解、Jackson 日期/空值/序列化配置
- 实战：添加统计定时任务；在课程中引入 Lombok 重构实体并配置 Jackson 格式化

第12周：部署、性能、面试准备与 Capstone 演示（2 次课）
- 目标：学会打包部署（Jar/Docker）、性能调优要点、面试演示与答辩
- 实战：打包运行、准备演示 PPT 与 10 分钟项目讲解、提交最终 PR

Capstone 要求（必做项）
- 完整的 `TrafficData` CRUD API（含分页、排序、过滤）、Swagger 文档与 Postman 集合
- MyBatis Mapper 与 SQL 优化说明（含索引策略）
- 全局统一响应、异常处理、参数校验覆盖
- AOP 请求日志/耗时埋点
- WebSocket 实时推送功能
- 多数据源配置示例与事务说明
- 定时任务统计并持久化结果
- 使用 Lombok 与 Jackson 的规范配置
- 提交 Git PR、包含单元/集成测试、README 与演示材料

考核与面试准备要点
- 编程题：常见数据结构算法与复杂度分析
- 数据库：索引、事务隔离、Explain 分析
- Spring：依赖注入、AOP、事务、自动配置原理
- 工程：Maven、Git、Docker、CI 基本概念
- 项目演示：10 分钟讲解 + 10 道常见后端题目答辩

运行与快速启动示例
```bash
# 在仓库根目录
mvn -T 1C clean package
cd green-traffic-api
mvn spring-boot:run
```
