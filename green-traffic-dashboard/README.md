# green-traffic-dashboard

前端资源目录（仪表盘 / 大屏） — 用于后续前后端分离开发。

目录目的：
- 存放前端代码、静态资源和构建配置。
- 与 `green-traffic-api` 后端分离，独立开发、打包与部署。

建议结构（示例）：

- green-traffic-dashboard/
  - README.md
  - package.json
  - src/
    - index.html
    - app/
      - main.js
      - styles/
  - public/
  - build/

推荐技术栈（可选）：
- 框架：React / Vue / Svelte（任选一种）
- 图表：ECharts
- 地图：Mapbox 或 Leaflet
- 构建：Vite 或 webpack

本目录已包含占位页面 `index.html`，后续我可以为你初始化一个 Vite/React 或 Vite/Vue 项目，或者把现有 `index.html` 移动到此处并做演示。
